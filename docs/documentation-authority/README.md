for terminal documentation authority across the Skill catalog. It is separate from
business repositories: project docs retain only product, UI, design, repository,
contract, and development facts.

- [Optimization plan](optimization-plan.md)
- [Frontend-unify validation report](frontend-unify-validation.md)

in ignored task storage. These documents contain only reusable current guidance and
the bounded evidence needed to decide the next Skill iteration.
